# Shared Computer Use Harness

Windows-native tools shared by Codex and Claude, operated by the laptop user and deployable to teammates. Browser, desktop and fast file/content search use installed executors; Jev supplies bounded judgments. The local read-only monitor shows actual wrapper runs, usage estimates and tool contracts. It must not expose credentials or create duplicate automation services.

## Platform
Web monitor served on loopback by Node; Windows x64 runtime and PowerShell 5.1 setup. Browser text generation can optionally use a separately installed local Ollama model. No Docker or WSL.

## Stack
Existing Node monitor serves prebuilt static React assets. Existing TypeScript MCP remains the tool interface. The user explicitly requires reuse of Chitragupta's UI and themes; this supersedes the prior plain HTML monitor style. Product function remains harness monitoring, not helpdesk ticket management.
